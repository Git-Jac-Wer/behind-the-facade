The visit, step by step

  1. ScanA visitor scans the QR sign next to an exhibit with the phone camera.
  2. OpenThe phone opens website-address#station-id, for example …/#pendulum. The part after # tells the site which station to show.
  3. ReadThe station page shows photos and the explanation, and (optionally) a quiz or an interactive add-on.
  4. StampAt the bottom the visitor taps Stamp my passport. The stamp is saved on the phone and appears in the passport.

The passport is the start page (#passport). It shows all stamps grouped by building, the progress, and a map with every station.

Where are stamps stored? In the visitor's browser (its "local storage"). There are no accounts and no server, so nothing is collected about visitors. The other side: stamps belong to one phone and one browser, and they disappear if the visitor clears the browser data or uses a private tab.

Add or change a station

  1. Put the photos into the images folder. Keep them under about 300 KB each (phones load them over mobile data); 1400 pixels on the long side is plenty.
  2. Open stations.js in a text editor (VS Code, Notepad++, or TextEdit in plain-text mode).
  3. Copy one whole station block, from { to },, and paste it where it should appear in the route.
  4. Change the fields. The id must be new and unique.
  5. Save and reload the page. The new station appears in the passport and the map, and gets its own QR sign.

A station block looks like this:

{
  id: "pendulum",                 // in the QR link: …/#pendulum, never change after printing
  building: "kip",                // id of a building from the BUILDINGS list
  title: "Foucault's pendulum",   // headline on the page
  teaser: "A brass ball that proves the Earth is turning.",
  draft: true,                    // shows a "draft text" label; remove when final
  photos: [
    { src: "images/pendulum-1.jpg", caption: "The ball swings over a ring of pins." },
    { src: "images/pendulum-2.jpg", caption: "A moment later." },
  ],
  sections: [
    { heading: "What you see", text: "A heavy brass ball …" },
    { heading: "What is going on", text: "First paragraph.\n\nSecond paragraph." },
  ],
  stamp: { shape: "circle", ink: "#2447a6", icon: "pendulum", label: "Pendulum" },
  map: { x: 66, y: 52 },          // dot on the map: x 0–100 (left→right), y 0–70 (top→bottom)
},

A new building works the same way: copy a line in the BUILDINGS list, give it a new id, and set where its block sits on the map.

Stamps

Every stamp is drawn by the site from four settings, so you don't need to make any graphics. The date of the visit is printed on it automatically.

SettingOptions
shape"circle", "hexagon", "square", "ticket"
inkAny colour code, e.g. "#2447a6". Medium-dark colours look most like real ink.
icon"pendulum", "field", "detector", "prism", "neuron", "printer", "star"
labelThe big word. Up to about 10 letters fits well.
imageOptional. Your own stamp picture (PNG with transparent background, or SVG), e.g. "images/stamps/pendulum.png". It replaces the drawn stamp.

Shapes and icons

A new icon goes into the ICONS list at the top of app.js: a small drawing on a 24 × 24 grid in SVG path notation.

Make the QR codes

  1. Put the site online first (next section). A QR code made from an address on your own computer only works on your computer.
  2. Write the public address into url at the top of stations.js, ending in /.
  3. Open the QR code page. It makes one sign per station, with the station name, building and code.
  4. Scan every sign from the screen with a phone and check that the right station opens.
  5. Save the signs (Download button, or right-click / long-press the image) and print them. The images are A6 at 300 dpi; at least 4 cm for the code itself scans reliably.
Codes stay valid when texts change. A code only contains the address and the station id. You can rewrite texts, swap photos and redesign stamps as often as you like without reprinting. Only changing the website address or an id needs new codes.

Put the site online

The site is just a folder of files with no server and no database, so any free static hosting works. GitHub Pages is the simplest:

  1. Create a free account on github.com and a new public repository, e.g. behind-the-facade.
  2. Click Add file → Upload files and drag in the whole content of this folder (index.html, the .js and .css files and the images and vendor folders).
  3. Open Settings → Pages. Under "Branch", choose main and / (root), then save.
  4. After a minute the site is live at https://your-username.github.io/behind-the-facade/. Put this address into url in stations.js.
  5. To change anything later, edit the file on GitHub (pencil icon) or upload a new version. The site updates after about a minute.

The university's own web space works the same way: upload the folder as it is.

Test before the trail opens

  • Every QR sign opens the right station on an iPhone and an Android phone.
  • Collecting a stamp works, and it is still there after closing and reopening the browser.
  • All photos load on mobile data, not only on Wi-Fi.
  • Texts are checked by someone from each institute; then remove draft: true.
  • The signs are allowed where you put them (ask the building management).
  • Use Clear my stamps at the bottom of the passport to start again.
Visitors can cheat. Anyone who types a station address gets the stamp without being there. For a campus trail that is fine. If it ever matters, a quiz about something only visible on site makes it harder.

Add-ons, once the basics work

Two kinds of interactivity are already built in, so you can try them on single stations:

  • Quiz: add a quiz block to a station (see ALICE). The stamp unlocks once the visitor has answered.
  • Widgets: small interactive pieces in widgets.js. The pendulum station shows the example: a time bar that shows how many pins have fallen after a chosen number of hours. A new widget is one function in that file plus widget: { type: "name" } on the station.

Ideas from the planning: draw a shape and watch it being 3D-printed, choose particles and see how the detector reacts, compare nerve signals with light and animals, move a "magnet" (your finger) over the arrow wall, and individual stamp artwork per station.
